Token Radar — a dashboard ranking 120 pre-token protocols by implied launch value, built from one sealed DefiLlama snapshot (14 Nov 2026). Model radar-2 prices a launch from TVL, seven-day growth and how long each protocol has run with no token recorded, and every row carries a four-step farm plan with what it costs and how long it takes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
